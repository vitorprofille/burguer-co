# Burguer & Co — Cardápio Digital

Versão profissional mobile-first em HTML, CSS e JavaScript puro.

## Funcionalidades
- Dark mode profissional
- Navegação fixa por categorias
- Status automático de abertura
- Produtos e preços
- Carrinho com quantidade +/−
- Resumo do pedido
- Checkout com nome, endereço e pagamento
- Mensagem automática para WhatsApp
- Layout responsivo

## Teste local
Abra `index.html` com Live Server no VS Code. Para testar pelo celular, computador e celular devem estar na mesma rede Wi-Fi; abra no celular o endereço local do computador, por exemplo `http://192.168.1.10:5500`.
